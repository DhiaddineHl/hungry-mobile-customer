# Hungry customer app — design export

## Open
- **Hungry Home Search (offline).html** — the full app board, all screens (sections 1a–4a). Opens in any browser, no internet needed except for fonts.
- **Design System Guide (offline).html** — visual index of the design system.

## For developers / Claude Code
- **handoff/DESIGN_SYSTEM.md** — start here. Complete implementation spec.
- **handoff/tokens.json** — machine-readable tokens.
- **handoff/theme/** — React Native theme (colors, typography, theme provider, Lucide icon wrapper). Copy to `src/theme/`.
- **handoff/assets/** — reference icons (Lucide SVGs) and brand assets.

## Editable source
- **source/** — the editable design files and their image assets. Open the .dc.html files with a local web server (e.g. `npx serve source`).

Screen IDs on the board (H1, R2, S-C2…) match the IDs in DESIGN_SYSTEM.md.
